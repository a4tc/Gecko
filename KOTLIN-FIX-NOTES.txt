GECKO PRESENCE 0.4.0 — PATCH NOTES

1. Existing Android layout compile fix retained:
   MainActivity.kt uses FrameLayout.LayoutParams for the child inserted into ScrollView.

2. IDLIX title extraction:
   - JSON-LD Movie.name has highest priority.
   - Shaka video aria-label and IDLIX player title are fallbacks.
   - Browser-support and asset-error gate headings are not treated as movie titles.
   - Document-title fallback strips the IDLIX suffix and leading “Nonton”.
   - Regression tests cover JSON-LD, Shaka video label, player title, and document-title fallback.

3. Android foreground app tracker:
   - UsageEvents queries moved off the UI thread to a dedicated HandlerThread.
   - Foreground event state is handled by a pure reducer with tests for selected/unselected resume, pause, stale pause, and screen-off.
   - Legacy foreground/background events are accepted alongside modern Activity events.
   - ACTIVITY_STOPPED is not used to clear the active package because it may refer to an older activity in the same package.
   - The Android Sources panel now displays live poll/event diagnostics and includes COPY DETECTOR DIAGNOSTICS.
   - Diagnostics retain only the latest status and selected app label; no usage history is persisted.

4. Custom Presence Studio added to PRD, roadmap, and design system:
   Separate from per-app/per-site Custom Rules. Planned controls include activity type, status-display type, name/details/state, large/small artwork, platform badge, up to two buttons, saved presets, preview, and manual override priority. This is a documented goal, not yet implemented in the app.

VERIFICATION
