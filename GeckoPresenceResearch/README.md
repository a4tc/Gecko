# Gecko Presence research archive

This directory contains retained PreMiD activity research, import lock metadata, upstream source notices, and historical architecture notes. It is not an application module and is not consumed by Gradle, Android runtime code, or CI packaging.

Gecko Presence 0.6.0 is native Android-only. No extension, XPI, PreMiD runtime, remote activity loader, or browser-side executable code is built or shipped. Research files remain for provenance, license compliance, and future adapter analysis only.

The documents under `docs/` may describe the earlier extension-based prototype. Treat them as historical unless explicitly updated to say otherwise. Do not restore their extension build steps to the product workflow.
